# Input, report and output files

[All issues](../README.md)

These issues are in the code that reads the input file and the external files it names, reads and writes hot start and interface files, and writes the report and the binary output file: in the legacy engines mainly `input.c` and the section readers, `hotstart.c`, `iface.c`, `runoff.c`, `statsrpt.c`, `massbal.c` and `output.c`, and in 6.0.0 the input handlers and the report and output plugins. In most of them invalid input is accepted or misread, valid input is refused or reported with a misleading message, or a result is stored or printed wrongly, and nothing warns the user. Three are 5.3.0 regressions: IO-39 (input warnings not counted) and the hot start defects IO-43 (dated saves) and IO-44 (Modified Horton state); IO-04 affects only 6.0.0, and in IO-24 and IO-25 the legacy engines are right and the manual is wrong. 6.0.0 reproduces 39 of the 62, six of them on purpose for parity with 5.3.0 (IO-13, IO-15, IO-39, IO-45, IO-53, IO-61).
